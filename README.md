# 朱引文庫 — 行政書士の学習書架

公開サイト: https://uni-tadayasu.github.io/gyouseisyoshi/

問題演習、必修カード、六法、用語辞典、裁判所公開裁判例を同じ画面で学ぶ静的Webアプリです。学習履歴は端末のブラウザに保存され、設定画面からJSONバックアップを保存・復元できます。

## 連続再生

各項目の「読む」または音声メニューから再生すると、絞り込み中の次の項目へ進みます。条文・用語・裁判例は表示ページを自動で切り替えます。「次の項目へ連続再生」を外すと現在の項目で止まります。前後移動、一時停止・再開、停止、音声速度とBGMの設定は共通です。

必修カードでは現在開いている答えを読み上げます。問題演習や模試の解答・採点を音声で自動操作することはありません。

## 判例書架

`#cases` から、事件名、事件番号、裁判所、年月日、裁判要旨を検索できます。スペース区切りはAND検索です。検索結果の順に再生でき、しおり・メモ・学習状態・4色マーカーを既存の学習バックアップに含めます。判例へのリンクは `#cases?id=公式ID` です。

対象は裁判所の公開裁判例検索データベース掲載分です。国内の全裁判の記録を意味しません。収録数、公式検索との照合方法、本文取得数、取得日、出典・ライセンスは [`cases/manifest.json`](cases/manifest.json) に記録します。本文の取得・抽出ができないものも検索と学習記録に対応し、公式ページへのリンクを表示します。本文を推測で補うことはありません。

公式本文・公式要旨と、主要34判例の学習用編集要約は画面で区別します。長文は2万文字ごとに表示し、読み上げは全文を対象にします。用語の下線から既存の用語辞典が開きます。

検索索引と本文はgzip形式で分割し、本文は選択した判例の分だけ取得します。全本文を初回にダウンロードすることはありません。HTTPS配信時は一度開いたデータをオフライン用にキャッシュします（ブラウザの保存容量に依存）。

## 開発・確認

```sh
python3 -m http.server 8000
npm ci
npx playwright install chromium
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
npm run test:browser
```

`http://localhost:8000/` を開きます。ブラウザ検証は既存の `/usr/bin/chromium` またはPlaywrightのChromiumを利用します。`CHROMIUM_PATH` で指定もできます。

単体テストでは再生キュー、停止後の非同期処理、バックアップ、実収録データの件数・一意性・本文ハッシュを確認します。ブラウザテストは音声モックと小さな判例データを使い、画面幅320〜1440px、検索、ページをまたぐ再生、しおり・メモ・マーカー、バックアップ復元を検証します。実際の声の品質はOS・ブラウザ・音声エンジンに依存します。

## データの更新と公開

[`tools/crawl-court-index.py`](tools/crawl-court-index.py) は公式一覧を低い並列数で取得し、途中経過を保存します。[`tools/import-court-cases.py`](tools/import-court-cases.py) は公開データと公式一覧を照合し、公式PDFから抽出した本文を分割保存します。各コマンドの引数は `--help` を参照してください。素材と取得途中のファイルは `work/` などリポジトリ外の作業領域に置きます。

GitHub Pagesは `main` ブランチのルートを公開します。PRのチェックを通した後にmainへマージすると公開されます。配信ファイルを変更するときは `index.html`、`sw.js`、`law-edition.js` と公開案内HTMLのリリース番号をそろえて更新してください。
