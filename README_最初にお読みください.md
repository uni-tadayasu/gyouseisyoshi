# 朱引文庫（SHUBIKI BUNKO）

行政書士試験のための私設書斎。既存「行政書士 MASTER ULTRA 六法版」を基に、デザインを独自制作したものです。

## 使い方
- Windows / Mac：`index.html` をChrome・Edge・Safariなどで開きます。単体起動版 `朱引文庫_単体起動_完全版.html` なら1ファイルだけで動きます。
- スマホ：ZIP内の全ファイルを同じフォルダー構成でGitHub Pages / Cloudflare Pagesに配置し、HTTPS公開後にブラウザでアクセスします。
- 公開：`index.html`、JavaScript、CSS、`assets`、`manifest.webmanifest`、`sw.js` を公開先のルートに配置。リポジトリにZIPのままアップしてもWebサイトにはなりません。

## デザイン・仕様
- 名前：「朱引文庫」。和綴じ・古典的な書架・和紙と朱印を組み合わせたオリジナルのデザイン。標準的なAI生成風の角丸ダッシュボードではなく、編集された書籍風の情報設計です。
- 背景、図案、書籍、封印、タブ、装飾はCSSで制作。外部フォント、画像CDN、アクセス解析は利用しません。
- PC / タブレット / スマートフォン対応（320px級を含む）。ダークモード、文字サイズ設定、フォーカス表示あり。
- 元アプリと同一の学習保存キー `gyosei_master_state_v2` と六法キーを維持し、データ互換性に配慮しています。
- 300問、六法閲覧、読み上げ、条文マーカー、模擬試験、学習分析などの機能を継承。

## 注意事項
- 六法の全文は配布ZIP内には同梱していません。e-Gov公式APIへの接続・法令本文取得が必要です。APIの仕様やCORS、アクセス条件によって取得できない場合があります。
- 初回に取得した法令本文はブラウザ内に保存されます。最新版との一致を保証しないため、必ずe-Govの原文をご確認ください。
- 日本語音声読み上げは、ブラウザ・OSの音声合成機能に依存します。
- 学習記録は端末・ブラウザ単位で保存されます。旧版から引き継ぐには同じ公開URL・同じブラウザで開くか、アプリのJSONバックアップ・復元をご利用ください。ローカルHTMLで開いた場合、ファイルごとに保存領域が分かれることがあります。
- 提供される300問は独自作成の学習素材です。正式な法令の解釈、法改正、試験主催者の最新要項・採点を保証しません。

## デプロイ・更新
1. 既存サイトのバックアップを取り、`index.html` 等をアップロードしてください。
2. GitHub Pages利用の場合、リポジトリ直下に`index.html`を置き、Settings → Pagesで公開してください。
3. 過去のPWAキャッシュが残る場合はブラウザの再読み込みか再インストールで改善します。
4. データ消失に備えて設定画面から定期的にバックアップを保存してください。
