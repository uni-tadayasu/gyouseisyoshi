# 朱引文庫　熟語辞典・全画面の音声・SEO 更新版

## 更新方法

1. 旧版の **設定 → バックアップを保存** で学習データを保存します。
2. ZIPを展開します。`index.html`、`laws/`、`assets/` など、展開した中身を現在のGitHub Pages公開元へ同じフォルダー構成で上書きします。公開元が `docs/` の場合は、その直下に配置します。
3. GitHub Pagesの更新完了後、いつものURLを同じブラウザで開いて再読み込みします。別のURLや端末に移行する場合は、更新版の **設定 → バックアップを復元** で手順1のJSONを選びます。

PCでは、展開した `index.html` をブラウザで直接開けます。スマホでは公開したHTTPSのURLを開きます。同じブラウザと公開元で、進捗、問題メモ、模試履歴、条文のしおり・マーカーを引き継げます。学習バックアップには、別途取得した法令の本文キャッシュは入りません。

## これだけは覚える

「今日の書斎」またはメニューから開けます。行政法・民法・憲法・商法と会社法・基礎法学・基礎知識・記述式の必修カード44枚を収録しています。問いに答えてからカードを開くと、答え、確認ポイント、用語解説、参照条文を確認できます。問題索引の関連科目・形式の演習へも移動できます。

「覚えた」「要復習」の状態は端末に保存されます。科目と状態で絞り込め、学習バックアップにも含まれます。

基準点は[令和7年度の合否判定基準](https://www.gyosei-shiken.or.jp/pdf/basis.pdf)を表示しています。[受験年度の公式案内](https://www.gyosei-shiken.or.jp/doc/guide/guide.html)で、その年度の基準を確認してください。

## 本文から引ける熟語辞典

収録15法令と44枚の必修カードの本文・見出しで、法律用語や一般の熟語に初期表示から下線が付きます。法律用語は二重線、一般用語は一重線です。辞典は3,970語です。下線を押すと意味と読み方が開き、その場で音声で読み上げます。参照条文がある用語は、解説から該当する条文を開けます。

用語辞典では表記、読み方、意味で検索でき、科目と法令で絞り込めます。出典とライセンスは `assets/dictionary-sources.txt` に記載しています。

## 全画面の読み上げとBGM

- 各画面の上部にある **音声 → この画面を読む** で、画面に表示されている文章を読み上げます。必修カードの **読む** は、問いと、答えを開いている場合は解答・確認ポイントを読みます。
- 下線の熟語を押したときは、用語名と表示中の意味を読みます。解説画面で **意味を聞く** を押すと繰り返せます。
- **本文と一緒に熟語の意味も読む** を有効にすると、文章を読み上げる際、出てきた用語の意味も各語につき一度読みます。
- **BGMを再生** で「Hear your voice」が流れます。その状態で文章や熟語を読み上げられます。読み上げ音量とBGM音量は別々に調整できます。
- e-Govの振り仮名と法令固有の読みを優先し、前後の語や句読点を保って日本語の音声エンジンに渡します。上部の **音声 → 発音と抑揚を試聴** で、選択中の音声を確認できます。語ごとの読みは、六法書架の **読み方を登録** で指定できます。
- GitHub PagesのHTTPS版では **内蔵日本語音声** も使えます。音声が自動設定の場合、BGM使用時、対応するiPhone・iPad、または端末に日本語音声がないときは内蔵音声を選びます。それ以外は端末の日本語音声を使い、高品質の音声が利用できる場合は優先します。初回だけ音声辞書を読み込みます。ブラウザでファイルを直接開く場合は端末音声を使用します。

- 対応するiPhone・iPadでは、再生を押すと読み上げとBGMをメディア音声として再生します。消音モード中も本体スピーカーで聞くには、出力先を本体にし、メディア音量を上げてください。公開したHTTPSページをSafariで開き、日本語音声は **自動** または **内蔵日本語音声** を選びます。

## 検索エンジン向けの公開設定

`learn.html`、`laws.html`、`dictionary.html` は、検索エンジンが本文をたどれる学習案内です。各ページに固有のタイトル・説明文・正規URL、SNS共有用メタデータ、構造化データを設定しています。

公開URLが確定したら、展開先で `python3 configure-seo.py "朱引文庫の公開URL"` を実行すると、正規URLと共有用URLが絶対URLになり、`sitemap.xml` が生成されます。Windowsでは `py configure-seo.py "朱引文庫の公開URL"` でも実行できます。生成後のファイルを公開元へ置き、Search Consoleにサイトマップを送信できます。GitHub Pagesのプロジェクト配下では、サイトマップのURLを直接指定します。

## 六法書架

**収録日　2026年11月12日（日本時間）**

- 主要六法6法令　日本国憲法、民法、刑法、商法、民事訴訟法、刑事訴訟法。
- 試験関連9法令　行政手続法、行政不服審査法、行政事件訴訟法、国家賠償法、地方自治法、行政書士法、会社法、個人情報の保護に関する法律、行政機関の保有する情報の公開に関する法律。
- e-Govの「憲法・法律」の公式目録2,103件を収録しています。追加法令の本文は、公式取得または公式XMLの取り込みで開きます。

条文は `95`、`９５`、`第九十五条`、`1条の3` のように検索できます。目次や問題解説のリンクからも移動できます。「表示範囲」から本則・前文、附則、別表・別記を選べます。

条文をドラッグするか、スマホで長押しして文字を選ぶと、4色マーカーと選択文の読み上げが表示されます。各条文には、しおり、読み上げ、メモ、リンクのボタンがあります。音声と速度は書架の読み上げ操作で変更できます。利用できる音声はブラウザ・OSに依存します。

## 読み上げ・BGM

- 六法書架で **BGMを再生** を押すと、添付曲「Hear your voice」を繰り返し再生します。BGMを流した状態で、条文や選択範囲の読み上げを始められます。
- **音声・BGM設定とマーカー** で、読み上げ音量とBGM音量を別々に調整できます。BGM音量はすぐに変わり、再生中の読み上げ音量は次の区切りから変わります。**読み上げ中はBGMを小さくする** で、声に合わせたBGMの音量調整を切り替えられます。
- e-Govのふりがな、法律用語、条番号を読み上げ用に処理します。たとえば「遺言」は「いごん」、「相殺」は「そうさい」、「競売」は「けいばい」です。読みが合わない語は、同じ設定内の **読み方を登録** に表記と読み仮名を入れます。
- 音量と登録した読み方は端末に保存され、学習バックアップでも引き継げます。BGMはZIPに同梱しています。GitHub Pagesでのオフライン利用は、初回オンライン表示時のファイル保存完了後に使えます。

- [e-Gov 法令標準XMLスキーマ](https://laws.e-gov.go.jp/docs/law-data-basic/419a603-xml-schema-for-japanese-law/)


ZIPを展開してPCで開くと、収録15法令と問題集を初回からオフラインで利用できます。GitHub Pagesでは初回オンライン表示時にオフライン用ファイルを保存します。追加法令の取得や公式サイトへの移動には通信が必要です。

## 問題と法令の出典

問題はオリジナル300問（五肢択一272問、多肢選択14問、記述式14問）です。模試は60問・180分・300点で、記述式は自己採点します。次年度向けの目標試験日は仮設定です。「設定」で変更できます。

2026年1月施行の行政書士法改正を反映し、業務・職責に関する5問の解説または参照条文を修正しました。問題IDと正解選択肢は引き継いでいます。

収録本文はデジタル庁のe-Gov法令API Version1から取得した法令標準XMLを閲覧用に整形しています。改正の施行日、経過措置、図表・様式・脚注や、試験の出題基準日時点で適用される条文は公式原文で確認してください。

- [e-Gov 法令API Version1](https://laws.e-gov.go.jp/docs/law-data-basic/8529371-law-api-v1/)
- [e-Gov 法令検索の利用規約](https://laws.e-gov.go.jp/terms)
- [行政書士法（2026年1月施行版）](https://laws.e-gov.go.jp/law/326AC1000000004?occasion_date=20260105)
- [行政書士試験研究センターの試験案内](https://www.gyosei-shiken.or.jp/doc/guide/guide.html)
