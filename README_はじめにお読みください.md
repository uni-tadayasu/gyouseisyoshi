# 行政書士 MASTER ULTRA — 2027年受験準備版

## 1. 最初の起動（Windows / Mac）

この ZIP をすべて展開し、フォルダー内の `index.html` を Chrome、Edge、Safari、Firefox などで開いてください。インストール不要です。ファイルの位置は変えず、`index.html`、`questions.js`、`advanced_questions.js`、`app.js`、`style.css` などを同じ階層に置いてください。

単一ファイル版 `行政書士MASTER_ULTRA_単体起動.html` も用意しました。こちらはほかのファイルを必要とせず、ローカルファイルとして起動できます。単体版はホーム画面への PWA インストールには対応しません。

## 2. スマートフォン / タブレット

ZIP の中身を GitHub Pages、Cloudflare Pages 等の HTTPS 静的ホスティングにアップロードしてください。`index.html` が公開サイトのルートに来る配置にします。ブラウザで開き、iPhone の Safari「共有→ホーム画面に追加」、Android の Chrome「メニュー→ホーム画面に追加」などでアプリ風に利用できます（表示・インストール方法は端末によって異なります）。初回アクセスでサイトのファイルが正しく読み込まれた後、サービスワーカーによるオフライン利用が可能です。プライベートブラウズ、ストレージ制限、端末側の設定により保存・オフライン動作ができない場合があります。

## 3. 搭載機能

- 収録問題：オリジナル 300問（五肢択一272、多肢選択14、記述14）。解説と参照法令・論点のヒントを掲載。
- 科目：基礎法学・憲法・行政法・民法・商法・一般知識・行政書士法等・情報通信/個人情報・文章理解。
- 問題演習：科目・難易度・形式・件数・出題方法・制限時間をカスタマイズ。混合出題、1問演習、途中中断と再開。
- 忘却対策：正誤・自信度・繰り返し回数に応じて間隔を変えるオフラインのルール型復習エンジン。
- 問題データベース：キーワード・科目・形式・学習状況・ブックマーク・メモ・要確認フラグで検索。
- 記述式：40字程度の答案作成、模範解答、配点ポイントと0～20点の自己採点。AIによる自動採点ではありません。
- 本試験形式の模試：60問・180分、見直しフラグ、問題ナビゲーション、時間切れ提出、参考合否基準、過去12回の全問再閲覧。
- 学習計画・分析：目標試験日、1日の目標問題数、学習時間、科目別進度、過去35日カレンダー、14日グラフ、模試得点推移、弱点論点。
- セキュリティ：利用データは端末のブラウザストレージに保存。サインイン不要・問題解答の外部送信なし。JSONバックアップ・復元。
- 見た目：ライト/ダークモード、文字サイズ調整、レスポンシブ、印刷。

## 4. 過去版の学習履歴を引き継ぐ方法

このアプリは旧「行政書士 MASTER」の学習データキー `gyosei_master_state_v2` と最初の193問の問題IDを維持しています。同じ Web サイトの URL で前版を更新する場合、ブラウザに保存された履歴を引き継げます。ただしブラウザが違う、端末が違う、単体HTMLファイルの位置や公開ドメインが違う場合は自動的な引継ぎを保証しません。

最も確実な方法：旧アプリの「設定」→「バックアップを保存」→ 新アプリの「設定」→「バックアップを復元」で JSON ファイルを読み込んでください。復元では現在の記録が**上書き**されます。念のため先に新アプリ側のバックアップを取得してください。

## 5. 採点について

本試験模試の配点は、法令等：五肢択一40問×4点=160点、多肢選択3問×8点=24点、記述式3問×20点=60点、合計244点。基礎知識：五肢択一14問×4点=56点。総合300点。通常の参考合格基準：法令等122点以上、基礎知識24点以上、総合180点以上。記述式は本人の自己採点を含み、公式採点・合否を保証するものではありません。

## 6. 大切な注意事項

- **2027年試験の実施日時・法令基準日は、作成日時点で未公表です。** 初期の目標日 2027-11-14 は仮置きで、正式日程ではありません。「設定」から変更できます。
- 令和8（2026）年度の公式試験案内を参考にした学習用アプリです。2027年度の試験科目・法令改正等については、公開後に公式情報を確認してください。
- 収録300問は独自作成の練習問題であり、公式の過去問題集・問題集出版社の内容ではありません。法改正・判例変更に対する自動更新機能や専門家の法的監修はありません。
- 不正解選択肢がかなり明確な基礎確認問題も含まれます。実際の合格力を測る際は、公式過去問・条文・判例と併用してください。
- ネットワークなしでも学習できますが、e-Gov法令検索・公式試験案内への外部リンクはインターネット接続が必要です。
- アプリを削除・ブラウザデータを消去すると記録を失うことがあります。バックアップを定期的に保存してください。
- 各種法律・判例の確認先： [一般財団法人行政書士試験研究センター](https://www.gyosei-shiken.or.jp/doc/guide/guide.html) / [e-Gov法令検索](https://elaws.e-gov.go.jp/)。
