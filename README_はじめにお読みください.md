# 行政書士 MASTER ULTRA 六法・読み上げ・マーカー搭載版

制作・改良：2026年11月12日。Windows、macOS、iPhone、Android、タブレットでの利用を想定した学習用ブラウザアプリです。

## 1. 起動方法

### Windows・Mac（単体起動HTML版）

配布された「行政書士MASTER_六法_単体起動.html」をダウンロードして、Chrome / Edge / Safari などで開きます。問題集300問と六法閲覧機能は同じ画面から利用できます。単体版に外部のCSS・JSは不要です。ただし初回の法令本文ダウンロード、公式法令一覧検索、外部の参考リンクは通信が必要です。ローカルファイルから公式APIへの通信がブラウザのセキュリティ設定等でブロックされた場合は、下記のGitHub Pages公開またはXML取り込みを利用してください。

### スマートフォン（GitHub Pages・Cloudflare Pages）

「行政書士MASTER_六法・読み上げ・マーカー_完全版.zip」を解凍し、**中の `index.html` が公開サイトのルートに来るように**、全ファイルをアップロードしてください。`roppo.js`・`roppo.css`・`sw.js`・`assets/` 等の配置は変えないでください。

公開URLをHTTPSで開き、iPhone Safariの「共有 → ホーム画面に追加」またはAndroid Chromeの「メニュー → ホーム画面に追加」で、アプリとして使えます。PWAとして追加できるかは端末とブラウザの機能によります。

## 2. 六法ライブラリの内容

法令の**閲覧対象一覧（カタログ）**は最初から収録しています。**公式法令の全文は配布ファイルに初期同梱していません**。法令を選んで「公式条文を取得して保存」を押すと、公開中の e-Gov 法令API Version1 から法令標準XMLを取得・変換し、閲覧できます。取得済みデータは IndexedDB に保存されるため、ブラウザの保存領域が有効であれば、オフラインでも再閲覧できます。

最初から選択できる15法令：

- **主要六法（6法令）**：日本国憲法、民法、刑法、商法、民事訴訟法、刑事訴訟法。
- **行政書士試験向け（9法令）**：行政手続法、行政不服審査法、行政事件訴訟法、国家賠償法、地方自治法、行政書士法、会社法、個人情報の保護に関する法律、行政機関の保有する情報の公開に関する法律。

さらに「e-Govの全法律から名前で探す」から公式「憲法・法律」一覧を取得して検索・追加でき、e-Gov法令IDを入力して別の法令を追加することもできます。**市販の『六法全書』の全内容を丸ごと同梱したものではありません**。e-Govから追加可能な法令範囲はAPIの提供・施行状況に依存します。

### 初回取得できないとき

インターネット接続を確認し、公式[e-Gov法令検索](https://laws.e-gov.go.jp/)の該当法令ページを開き、そこから原文XMLをダウンロードしてください。六法画面の「e-Gov法令XMLを取り込む」から読み込めます。必要に応じて先に該当する法令を一覧から選択してください。XML取込ファイルは28MB以内です。別の法令のXMLを誤って選ぶと、法令名の不一致で拒否します。

## 3. 音声読み上げ

- 条文カード右上の🔊ボタン：その条文を読み上げます。
- 「このページを読む」：表示中の条文を連続して読み上げます。
- 文章を選択して「選択文を読む」：選択した部分のみ読み上げます。
- 速度：0.7～1.5倍。再生中は一時停止／再開、停止が利用できます。
- 読み上げはブラウザの Web Speech API を使用し、端末の利用可能な日本語音声を優先します。日本語音声がない場合、端末の読み上げ環境によって発音が不自然になったり、音声が出なかったりします。ユーザー操作後に再生する設計です。
- **画面・タブが非表示になった場合は読み上げを停止**します。バックグラウンドで音声が流れ続けないようにしています。OSごとの実際の挙動は異なります。

## 4. カラーマーカー線・条文ブックマーク・メモ

1. PC：マウスで条文内の語句をドラッグします。スマホ：文章を長押しして必要な範囲を選択します。
2. 「マーカー線」の黄・緑・桃・青のいずれかを押すと、選択した文字の範囲に背景色＋下線型マーカーが付きます。記事中の複数段落にまたがる選択にも対応しています（ブラウザが選択範囲を提供する場合）。
3. 条文右上の☆でブックマーク、✎で学習メモを記録できます。保存済みのマーカーは「マーカーを管理」から個別削除できます。
4. 法令を更新したとき、同じ文字位置が別の文章を指す恐れがあるマーカーを照合します。照合できないものは「本文変更・要確認」として管理画面に表示し、誤って色を付けないようにしています。

学習ノート・マーカー・ブックマークはブラウザのローカルストレージに保存されます。ブラウザのプライベートモードやデータ削除・容量不足の場合、保持できない場合があります。

## 5. 問題集と模擬試験（前回版の機能は維持）

- オリジナル問題300問：五肢択一272問、多肢選択14問、40字程度の記述式14問。
- 科目別・難易度別演習、正答率、弱点分析、間隔反復、問題ごとのブックマーク・メモ・要確認フラグ。
- 本試験参考形式模擬試験60問・180分・300点満点。法令等122点、基礎知識24点、総合180点の通常参考基準を表示。記述は採点ポイントによる自己採点。
- 学習計画・学習履歴・過去模試のアーカイブ。

**2027年度の試験日等の正式発表前のため、初期の目標試験日は仮設定です。** 2026年度の制度を参考にした学習用の実装であり、問題の法的な監修や法改正への自動更新、合格保証はありません。

## 6. レスポンシブ対応

- PC：左側アプリナビ、法令ライブラリの2カラム（法令一覧＋本文）。
- タブレット：画面幅に応じて法令一覧と本文の幅を調整します。
- スマホ：六法の法令一覧を開閉できる1カラム、下部タブバー、タッチ操作に適したボタン、横幅に合わせたマーカー色選択・読み上げパネル。
- テーマ：ライト／ダーク。文字サイズの拡大設定も維持しています。
- 画面幅320、360、390、430、670、768、900、1024、1440pxでブラウザレイアウトテストを実施し、横方向のはみ出しは検出されませんでした。**全端末実機でのテスト・すべてのブラウザでの正常動作の保証ではありません**。

## 7. バックアップ・復元

既存の「設定 → バックアップを保存」から、**学習履歴と六法マーカー・条文メモ・ブックマーク**のJSONを保存できます。以前の行政書士MASTERと同じ問題IDと学習データキーを維持しています。復元時は現在の学習データが置き換わります。

**法令全文のキャッシュ本体（IndexedDB）は学習バックアップに含まれません。** 新しい端末では公式APIから再取得するかXMLを取り込んでください。旧アプリが別のURL・ドメインだった場合はJSONバックアップ・復元でデータを引き継いでください。

## 8. 法令データの注意事項・出典

公式APIから取得した日付は、**その法令の施行日を示すものではありません**。公布済みの未施行規定・改正予定・施行日・附則・経過措置・図表・脚注などは、アプリの読みやすさ重視のテキスト表示では完全に再現できない場合があります。個別の学習判断・条文引用・法律実務には、必ず公式e-Gov法令検索の該当時点の原文を確認してください。

- [e-Gov法令検索](https://laws.e-gov.go.jp/)
- [e-Gov法令API Version1の説明](https://laws.e-gov.go.jp/docs/law-data-basic/8529371-law-api-v1/)
- [e-Gov法令XMLの構造説明](https://laws.e-gov.go.jp/docs/law-data-basic/8ebd8bc-law-structure-and-xml/)
- [行政書士試験研究センター](https://www.gyosei-shiken.or.jp/)

## 9. ZIPの中身

- `index.html` — 起動入口
- `app.js` — 問題演習・採点・学習履歴・模試
- `questions.js`, `advanced_questions.js` — 300問の問題データ
- `style.css`, `roppo.css` — PC・スマホのレスポンシブ画面
- `roppo.js` — e-Gov法令取得・閲覧・読み上げ・マーカー・保存
- `manifest.webmanifest`, `sw.js` — PWAと基本アプリのオフラインキャッシュ
- `assets/` — アイコン
- `CHANGELOG.md` — 変更内容

注意：GitHub Pages/Cloudflare Pagesへアップする場合、ZIPファイルをそのまま配置するのではなく、中身を展開し `index.html` をサイトの公開ルートへ置いてください。
